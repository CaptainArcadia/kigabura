# キガブラ

ブラウザで遊べる、最大4人の大乱闘アクションゲームです（Three.js 製）。
キャラクターは `image/` の設定画をもとに 3D で作っています。

## 起動のしかた

- **いちばん簡単**：`index.html` をダブルクリックして Chrome / Edge で開く
- うまく動かないとき：`サーバーで起動.bat` をダブルクリック（Python が必要）→ ブラウザで `http://localhost:8765/` が開きます

※ Three.js と Google フォントをネットから読み込むので、インターネット接続が必要です。

## 遊び方

タイトル → 大乱闘 → キャラ選択 → ステージ選択 → ファイト！

- 相手を攻撃して **ダメージ%** をためると、ふっとびやすくなります
- 画面の外までふっとばせば **撃墜**
- ルールは **ストック制**（1〜9機）と **タイム制**（1〜9分、同点ならサドンデス）
- CPU は Lv1〜9。4人全員 CPU にして観戦もできます

### 操作

| 操作 | キーボード1 (P1) | キーボード2 (P2) | ゲームパッド |
|---|---|---|---|
| 移動 | A / D | ← / → | 左スティック・十字キー |
| ジャンプ | W / Space | ↑ / テンキー0 | X / Y（スティック上でも可） |
| しゃがむ・床から降りる・急降下 | S | ↓ | スティック下 |
| 攻撃（方向と組み合わせ） | J | テンキー1 / `.` | A |
| スマッシュ攻撃（長押しでため） | U | テンキー4 / `;` | 右スティック、またはスティックをはじきながらA |
| 必殺ワザ（方向で4種類） | K | テンキー2 / `/` | B |
| シールド（＋方向で回避） | L / 左Shift | テンキー3 / 右Shift | RB / LT / RT |
| つかみ → 方向で投げ | I | テンキー5 / `:` | LB |
| ポーズ | Esc / P | Esc / P | START |

崖につかまったら、上か横で登る・ジャンプで飛び上がる・攻撃で崖のぼり攻撃・シールドで転がり登り。
ふっとばされて着地する直前にシールドで **受け身**、ふっとび中に方向キーで **ずらし** ができます。

### キャラクター

| キャラ | タイプ | 必殺ワザ（通常 / 横 / 上 / 下） |
|---|---|---|
| ATARU（覆面神父） | 重量級・パワー | ホーリークロス / フライングボディプレス / 昇天ホーン / 懺悔カウンター |
| FURA（氷の妖精） | 軽量級・3段ジャンプ | アイシクルショット / フリーズダッシュ / 妖精の羽ばたき / パーフェクトフリーズ（凍らせる） |
| MG（祭り猫） | 超重量級 | あつあつたこ焼き / ころころアタック / ねこロケット / ヒップドロップ |
| SIKO（紅白ボーダー） | 中量級・トリッキー | ボーダー砲 / つっぱり / 筒ロケット / 四股踏み（衝撃波） |

同じキャラを複数人で選ぶと、自動で別カラーになります（キャラ選択の「カラー」でも変更可）。

### ステージ

- **夏祭り 神社境内**：すり抜け床3枚。提灯と屋台、夜空に花火
- **氷の湖**：左右の床＋左右に動く氷の床
- **星降る終点**：足場なしの平坦なステージ

## ファイル構成

```
index.html        画面の骨組みと読み込み（three.js はここで CDN から読み込み）
style.css         HUD・メニューの見た目
src/core.js       共通処理・入力（キーボード/パッド）
src/audio.js      効果音と BGM（すべてその場で合成）
src/tex.js        Canvas で描くテクスチャ（顔・柄・ステージ素材）
src/models.js     4キャラの 3D モデル
src/anim.js       アニメーション（状態ごとのポーズ）
src/moves.js      キャラ性能とワザのデータ ← バランス調整はここ
src/fighter.js    ファイターの動き・物理・被弾処理、飛び道具
src/effects.js    ヒット・撃墜などのエフェクト
src/stages.js     ステージ（当たり判定と背景）
src/ai.js         CPU の思考
src/hud.js        試合中の表示（ダメージ%・名札など）
src/game.js       試合の進行・当たり判定・カメラ・ルール
src/ui.js         タイトル・キャラ選択などのメニュー
src/main.js       起動・描画ループ・メニュー用3Dシーン
```

### 調整のヒント

- ワザの強さは `src/moves.js` の `H(開始, 終了, 前方x, 高さy, 半径, ダメージ, 角度, 基礎ふっとばし, ふっとばし成長)` を変えます
- 走る速さ・ジャンプ力・重さはキャラごとの `stats`
- ふっとびの全体的な強さは `src/core.js` の `KB_SPEED`（大きいほど飛ぶ）
- 画質が重いときは「せってい」→ 画質を「中」か「低」に
